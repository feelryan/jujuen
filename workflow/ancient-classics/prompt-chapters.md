你是一位專精中國古籍與教育設計的大師，為指定的一本古書規劃「章節目錄（Category 清單）」。

## 任務說明

我會提供：
- 書名（繁體中文）：`{book_title_traditional}`
- 書名（英文）：`{book_title_english}`
- 書的代號（id）：`{book_id}`
- 一份來自 `content.info` 的章節資訊 JSON：

```jsonc
{chapter_info}
```

其中 `chapter_info.chapters` 已經是「依正確順序排列的、完整的章節名稱列表（繁體中文）」；`isChatpersCompleted` 為 true 時，代表這個列表已經完整列出所有章節。

請不要自行新增、刪除或重新排序章節，只能針對這些既有章節名稱，補上 Category 所需欄位（id / t / c / p / z / en）。

重點：
- 這份清單會被用來當作 Category JSON 的 `items` 欄位。
- **只需要產生章節本身，不要產生測驗或題目項目**（quiz/問題 會在程式中另外加）。
- 章節的數量與順序必須與 `chapter_info.chapters` 完全一致。

## 輸出格式（非常重要）

請務必輸出「純 JSON 陣列」，不能有 Markdown 語法、註解或多餘文字。

JSON 陣列中的每個物件格式如下（對應 Category 的 item）：

```json
[
  {
    "id": "chapter01",          // 章節代號：全英文+數字、不含空白，建議依序使用 chapter01, chapter02, ...
    "t": "學而",             // 章節標題（繁體）
    "c": "学而",             // 章節標題（簡體）; 若不確定，可與繁體相同
    "p": "xué ér",        // 拼音;
    "z": "ㄒㄩㄝˊ ㄦˊ", // 注音; 
    "en": "To learn"   // 中文語境的英文翻譯或簡短說明
  }
]
```

規則：
- 一定要回傳 **JSON 陣列**，最外層不可是物件。
- 陣列中的每一個物件，必須一一對應到 `chapter_info.chapters` 中的每一個章節名稱，且順序相同。
- 不要新增額外章節，也不要刪除任何章節。
- 每個物件 **至少** 要有欄位：`id`, `t`, `en`。
- `id` 必須是穩定的英文代號：
  - 僅能使用英文字母、數字與短橫線（`-`）。
  - 不可包含空白或中文。
  - 建議形式：`"chapter01"`, `"chapter02"`, ... 依實際章節順序遞增。
- `t` 一般情況下應直接使用對應的章節名稱；如需微調，請保持語義與傳統用法一致。
- `c`, `p`, `z` 請盡可能填寫正確內容；如確實不清楚，可暫時與 `t` 相同或留為合理近似。
