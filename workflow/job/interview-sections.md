## A. 招聘流程節點（從接觸到拿 offer）

1.  **Recruiter Screen（15–30 分）**
    *   角色匹配（職稱、職級、技術主軸）、動機與職涯方向
    *   地點/遠端、到職時間、薪酬區間、**工作簽證/移民**（含 L‑1B 現況與轉換可能）
    *   流程說明與準備建議、必要材料（作品/簡歷版本）

2.  **Hiring Manager Screen（30–60 分）**
    *   **自我介紹（Tell me about yourself）**（3–5 分鐘版）
    *   **目前/最近專案深挖**（目標、指標、關鍵技術、權衡、風險控管）
    *   職責範圍與影響力、跨部門協作、優先級管理與風險處置
    *   對團隊需求與職缺定位的雙向提問

3.  **技術 Phone/Virtual Screen（45–60 分 × 1–2 場）**
    *   **線上程式題（Coding/DS\&A）**：陣列/字串、雜湊、雙指針、滑動視窗、堆/優先佇列、圖/DFS/BFS、設計題簡版等
    *   **迷你系統設計（或 API 設計）**：資料模型、端點、索引、快取、一致性與伸縮性
    *   **Debug/Refactor/Code Review**：可讀性、安全性、效能 trade‑off

4.  **Onsite / Loop（半天～一天，3–5 場）**
    *   **系統設計（Large‑Scale System Design）**：延展性、高可用、分區/複寫、併發、韌性、成本
    *   **後端/資料/搜尋實作面**：資料建模（EER/正規化）、交易與一致性、**ElasticSearch 索引與查詢策略**、快取（Redis）
    *   **雲端 & DevOps / CI‑CD**：GCP/AWS 服務選型、容器化、部署策略（藍綠/金絲雀）、安全與合規
    *   **品質與測試策略**：單元/整合/回歸、自動化、測試資料與覆蓋率
    *   **行為面試（Behavioral / Leadership）**：Ownership、衝突化解、失敗復盤、影響力與跨部門協作
    *   **Bar‑raiser / Culture Add（部分公司）**：價值觀與決策思維的深度對談

5.  **Team/Founder Chat（選配）**
    *   業務/產品路線圖、與你背景的互補性、未來成長空間與技術債優先序

6.  **Offer/Reference Check / 背景查核**
    *   推薦人驗證、教育/就業背景、（醫療/政府專案常見）合規或安檢流程
    *   薪酬與職級談判、入職安排/簽證配套

> 上述流程結構會依公司規模/領域略有不同，但核心面向一致；我後續會針對你目標公司的「輪次與配比」做微調腳本。

## B. 依你的背景延伸的 **技術/情境專章**（用於各輪深挖）

### 1) 自我介紹（3–5 分鐘 & 60 秒電梯版）

*   敘事骨架：**角色定位 → 代表性戰績（醫療影像雲 / 電商支付 / 搜尋）→ 技術主軸（Java/Spring、TS/React/Node、GCP/CI‑CD、MySQL/Elastic/Redis）→ 當前目標**。

### 2) 目前/最近專案深挖（Project Deep‑Dive）

*   **醫療影像雲（Imaging Share / Archive on GCP）**：PHI/合規、安全設計、可用性/效能優化、跨公私雲驗證、你在 CHC EI 的具體產出與量化指標。
*   **搜尋/索引（ElasticSearch）**：索引策略、分片/副本、映射/Analyzer、查詢功能（多欄、多語、相似度/建議）、延遲與吞吐監測。
*   **電商支付/錢包**：三方金流整合（PayPal/CardConnect）、\*\*數位錢包（BTC/ETH）\*\*與 **RSA 簽章**安全機制、風控與稽核需求。

### 3) 系統設計（含多種題型）

*   **高流量上傳/分享醫療影像服務（DICOM 檔案）**
*   **產品搜尋（ES）與自動完成功能**
*   **支付結算/錢包帳務一致性（最終一致 vs 強一致）**
*   **事件驅動的審計/合規日誌管線**
*   **多租戶 SaaS 架構（分區、配額、隔離）**  
    （每題均含：需求澄清 → SLA/SLO → 資料模型 → 元件與通訊 → 伸縮/快取/CDN → 一致性與容錯 → 觀測性 → 成本）

### 4) 後端資料與 API 設計

*   EER 建模、索引選擇、交易邊界、避免 N+1、分頁/排序/一致性
*   API 版本化、冪等性、速率限制、金鑰管理與審計

### 5) 搜尋與效能優化

*   ES 索引設計、Relevance 調參、快取策略（應用層/ES 層/Redis）、冷熱資料分層、批處理與近即時刷新

### 6) 雲端架構 & CI/CD（GCP、AWS）

*   服務選型（GCS、GKE、Cloud Run、Pub/Sub、BigQuery…）、IaC、祕密管理、零停機部署、回滾策略
*   **Pipeline 設計（GitHub/GitLab/Jenkins）**、品質門檻（Lint/Test/Coverage/SAST/DAST）、合規與簽署
*   成本治理與容量規劃

### 7) 安全與合規（你的醫療/政府經驗可加分）

*   **醫療**：PHI/PII、最小權限、加密/簽章、稽核追蹤、資料主權與備援
*   **支付**：PCI 考量、金流風控、簽章與重放防護
*   **政府/告警**：訊息可靠性與鏈路可視性  
    （此章節可搭配你曾打造的 **安全強化與測試流程** 作答）

### 8) 測試策略與品質工程

*   測試金字塔（單元/整合/端到端）、資料準備、回歸自動化
*   故障注入、混沌工程、SLO‑error budget 與品質門檻設定

### 9) 觀測性與可維運性

*   指標/日誌/追蹤（如 OpenTelemetry 思路）、警示閾值、Runbook、On‑call/Incident 流程、RCA/事後檢討

### 10) AI‑assisted Development / GenAI 應用（結合你的 **Generative AI Leader**）

*   你如何以 Copilot/LLM **提升交付速度與程式品質**（複審機制、避免過度依賴）
*   **負責任 AI**：資料/隱私、偏誤與幻覺風險、RAG/評測、在 SDLC 中導入的切入點
*   在產品/平台中的實際落地（如文件生成、支援人員知識檢索、Code Review 輔助）  
    （此章節凸顯你「策略＋工程落地」雙能力）

### 11) 行為面試（STAR 法）

*   **領導力與影響力**：跨部門對齊、說服/衝突化解、決策權衡
*   **Ownership/Deliver Results**：風險管理、期限壓力、技術債處理
*   **失敗復盤**：事故處置、學習與制度化改善
*   **培育與協作**：Mentoring、Code Review、Pair/內訓

## C. 工作簽證／移動（Immigration & Mobility）專章

> 典型會在 **Recruiter Screen** 或 **Final/Offer** 階段出現，少數會在 HM Screen 確認。

*   **目前簽證狀態**（例：**L‑1B** specialized knowledge）與 **到期日/寬限期**
*   是否需 **雇主支持轉換/延展**（例：L‑1B → H‑1B/EB‑類、公司內部調動）
*   地點偏好（州/國）、遠端政策、出差頻率
*   時間線限制（入職時間、現職交接期）

> 我們不在此提供法律建議，但會幫你準備「**簡明且風險可控**」的溝通話術與 FAQ 答案，避免在早期輪次暴露過多細節，同時不影響流程推進。

## D. 其他常見（但易忽略）的章節

*   **Pair Programming / Take‑home**：可要求你用熟悉技術（Java/TS）完成小題或與面試官協作
*   **Code Review Round**：從可讀性、測試性、安全性、效能提出具體改進
*   **Product/Customer Empathy**：你如何把臨床/商業需求轉成技術規格與可量化指標（醫療/支付場景特別加分）
*   **Artifacts/Portfolio**：簡版架構圖、API 規格、測試/部署流水線截圖、效能報告（去敏後）
